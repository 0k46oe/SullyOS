# 头像上传与裁剪

个人档案的整体头像、分角色聊天头像以及神经链接的角色头像，本地上传后共用 useAvatarCrop / AvatarCropDialog：拖动图片，1～4 倍缩放，重置，确认后才更新头像。取消、系统返回、Escape 或退出上传页面均不替换已有头像。

裁剪输出方形 PNG，最长边 512px，不放大低分辨率原图，保留透明通道；圆形参考线仅供预览，聊天装扮仍决定最终头像形状。保存沿用 migrateDataUrlToRef，不改变用户 / 角色 / 分角色覆盖的数据结构。分角色覆盖仍按角色 ID 保存，不影响整体头像。

「保留原图」沿用已有图片处理器；GIF 保留原始动图，若确认裁剪则明确保存为静态头像。不自动处理角色卡导入的头像或外链 URL，避免改变角色卡导入与通知图标语义。

图片仅在本地临时 object URL 中预览，关闭释放；上传超过 50 MB 或解码尺寸超过 4000 万像素时提示。预览与导出使用同一个源图裁剪矩形，边界始终夹在图内，避免拖出空白。弹窗通过 body portal 展示，接入局部返回层 80，移动端可滚动。

回归：pnpm vitest run utils/avatarCrop.test.ts；另检查手机拖动、取消、缩放后的实际输出、透明 PNG 和保留原始 GIF。三个上传点的图片令牌链路由 utils/storageOptimize.test.ts 继续守卫。
