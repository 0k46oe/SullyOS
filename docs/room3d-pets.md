# 七只纯色宠物素材

## 定时回窝 / 跳床睡觉（2026-10-05）

开启宠物自由活动时，按小屋时区在 22:00–08:00 优先安排睡觉，白天精力低于 30 也优先休息。只在当前房间找可达位置，优先休息垫，再选已校准的普通床（show_bed、单人床、双人床）；高架床和上下铺暂不支持。没有可达睡位时保留原有本地行为。

`petSleep.js` 选择床尾落点，避开居民和旁边家具，同一家具只保留一个宠物睡位。地面寻路完成后用 0.8 秒跳跃上床，实际落下才记录睡觉。夜间保持睡眠，白天精力恢复后跳下，普通小睡 30 秒。呼唤、照顾、抱起会先跳回预留地面位置；醒来后 60 秒内不重新抢睡位。关闭自主活动、家具失效会退出睡眠，挂起/隐藏页面不推进动作。存档仍保存安全地面位置。全部本地执行，不调用 LLM。

验证：petSleep、room3dPetLife、room3dPetContact 共 25 项测试；隔离测试房检查实际床面位置与早晨落地。

输入：用户提供的 `Meshy_AI_assets_20261002_154155.zip`，按包内顺序为小鸟、盘蛇、史莱姆、猫、狗、乌龟。几何制作源保存在 `art/pets/sources/1.glb` 至 `6.glb`，已去掉所有图片、UV、顶点色。原始带贴图文件仅留在本地 `output/pets/raw/`，不用于运行时。

七个素材既可作静态摆件，也可通过「宠物」领养为独立居民。选中旧宠物摆件 →「成为家园宠物」可保留其配色并转换；复制普通摆件不会复制宠物身份和记忆。

## 家园宠物生活 · 2026-10-03

正式入口：家园底栏「日常」旁的「宠物」，或「我的家 → 宠物」。最多 7 只，每只选择至多两种性格；支持改名、56 套预设与每个部位自定义颜色。

- `petState.js` 验证持久数据；`petLife.js` 负责需求、候选行动、寻路与互动完成；`petSystem.js` 负责整块模型动画、射线选择和独立面板。正式 `Home3DView` 通过现有编辑器加载，不依赖预览代码。
- `home3D.petLife` 保存宠物 ID、所在房间、坐标、性格、饱食/精力/亲近/趣味、关系、近期记忆、食盆份数和最近 80 条宠物小记。需求都是满意度，100 最满足。模型模板、运行中路径和动作不进入存档。
- 所有物种共用跳跃行走、俯身吃饭、摇摆玩耍、轻微缩放休息。没有骨骼动画、物种专属飞行或爬行，也不调用 LLM。
- 行为完成后才重新选择：先排除空食盆、不可达目标、忙碌居民及已占用用品，再按需求、性格、关系、距离和重复惩罚加权，从前三项中抽取。低需求增加权重；正在执行的动作保持到完成、目标失效或手动打断。
- 采用宠物实际缩放后的保守占地半径与高度、现有寻路器和独立障碍缓存；逐步移动时检查其他宠物与居民，遇阻取消路径，不跨越家具或房间。角色不被宠物强制切换动作。
- 食盆 `pet_bowls` 手动补满 5 餐，吃完扣一餐；新加 `pet_toy_ball` 和 `pet_rest_mat`，分别 168/128 面，纯色无贴图。玩具/休息垫需要真实存在且可达。没有休息垫时允许原地睡觉。
- 「摸摸 / 喂一点 / 陪它玩 / 叫过来 / 让它休息」在动作完成后增加需求。叫过来需要用户小人在同房间且可达；直接抚摸、零食与陪玩是用户从界面的照顾操作。重复点击不会叠加动作，关系增益有 30 秒活动时间冷却。
- 记忆记录实际喂养者、陪玩者、休息垫实例 ID、近期行动及居民 ID 关系。记录领养、手动互动完成和食盆进食，保留「宠物小记」，同时把实际发生的领养、用户照顾与食盆进食写入家园日常，沿用家园回合投影进入共用上下文；不伪造恐惧经历，不冒充角色说过的话。
- 只推进当前正在观看的房间；装修、总览、页面隐藏、家园挂起时暂停。没有离线衰减或离线事件补算。切房间不携带宠物，跨房跟随留待后续。
- 宠物状态独立于装修撤销快照；布局撤销和运行中的布局导入保留当前生命状态。转换过的摆件 ID 会被持续去重。房间被删除时安置到当前房间；刷新/重新打开家园则读取正式存档。
- 每 15 秒活动时间、互动完成、配置更改和离开时保存；没有宠物的家园不运行宠物模拟。忙碌居民不会被选为撒娇目标，互动路径失效或用品被搬走时不发奖励。

完整共同生活预览：`/test/fixtures/home-pets.html`（七只宠物、两个小人，独立内存数据，不写用户家园）。持久化验证页：`/test/fixtures/room3d-pet-life.html`（使用独立 `test-pet-life` 本地存储）。原素材转台仍为 `/test/fixtures/room3d-pets.html`。

验证：`pnpm vitest run utils/room3dPetLife.test.ts utils/room3dPets.test.ts`；`pnpm node art/pets/life-qa.mjs` 实测桌面与 390px 手机、喂养完成、暂停、改名、预设、恢复/局部换色、刷新和容量限制。`art/pets/supplies.mjs` 可重建小球/休息垫。

## 自定义配色

`art/pets/register.mjs` 定义每种 8 套、共 56 套色板。命名是物种/常见毛色的配色参考，不代表改变品种、几何花纹或材质贴图。色板完整写入目录 `colorPresets`，可编辑部位由 `colorParts` 显式列出，材质名统一 `pet-*`。

`paintPanel.js` 为已有家具换色面板增加成套预设；宠物的细部颜色可展开自选，手机面板限制高度并滚动。原“枕头恢复原色”硬编码改为通用局部恢复，宠物提供全部恢复。

- 预设解析成实例的 `materialColors`，不增加新的存档版本或运行时预设 ID。
- 自选主体颜色先清掉预设对主体材质的覆盖，再写入 `color`；其他部位保留。
- 细部控件显示实际生效颜色；预设选中态由最终颜色判断。
- 复制深拷贝、撤销/重做、保存/导入都复用现有房间机制。新实例不会继承另一只的改色，共享 GLB 模板不会被污染。

## 宠物小屋面板

入口沿用小屋菜单与场景宠物按钮，点击场景里的宠物先打开环形动作菜单，「宠物面板」是其中一个动作。独立面板沿用 islandTheme 的奶油点纹、暖棕文字和青绿强调色。

- 伙伴页：七种宠物的实际模型肖像、所在房间、需求提示；领养和自由活动开关。
- 详情：照顾 / 装扮 / 小记。照顾显示四项需求、实际亲密度及阶段称呼，提供摸摸、喂零食、一起玩、叫过来、休息。装扮保留改名、默认配色及部件颜色。
- 互动显示当前动作和进度；进行期间避免重复提交。完成收益取自运行时 `result`，只在实际完成时反馈，取消不冒充完成。暂停时进度冻结；离开宠物所在房间不能发起互动。
- 用品页为食盆补粮，小记展示已有生活事件。没有新增货币或虚构奖励；所有宠物共享整块模型的简单动作。
- `petPortraits.js` 用一个懒加载渲染器生成透明肖像，按宠物配色缓存，面板不增加持续渲染循环，销毁时释放。移动端可滚动，支持 Escape、焦点循环和减少动态效果。

验证：`art/pets/life-qa.mjs` 覆盖原有完整生活流程；`art/pets/panel-qa.mjs` 覆盖肖像、用品、互动进度与完成、小记、取消、暂停及手机布局。

## 人物接触宠物

「摸摸」现在由用户小人执行：寻路到宠物身边 → 蹲下 → 手部 IK 触摸头部 → 起身。头部接触点由眼睛定位并向模型表面投射，避免把猫尾巴或鲨鱼背鳍当成头；另一只手放在膝前。复用现有 48 骨形象、脚底校正和衣服跟随，不改变骨长。

「抱起来」先靠近、蹲下，再把整只宠物横抱到胸前。双手目标与宠物位置共用同一坐标，行走保留腿部动作、覆盖双臂姿态。面板自动收起；直接点地面走动，通过场景提示条或宠物面板「放下来」落地。落地搜索宠物可站立的空地，周边无空位时保留抱持并提示换位置。

- `petContact.js` 管理 approach / stroke / lift / held / lower。`petLife` 的 external runtime 暂停该宠物自主行为，摸摸实际完成后才结算，抱持本身不刷亲密度。
- 暂停保持姿势/进度；切换人物、房间、布置或开始其它动作会结束接触。当前支持在同一房间抱着走，跨房间不携带。缺少用户小人或骨骼形象时给出提示。
- 抱持不写入长期状态；保存的是附近有效地面位置。重建/换色保持现有宠物实例，取消不会复制、丢失宠物或吞掉新的人物动作。
- 验证：`room3dPetContact.test.ts` 检查接近阶段不奖励、摸摸结算、取消、暂停、抱持移动/转向、落地与骨长/脚底/接触约束；`art/pets/contact-qa.mjs` 检查真实用户小人、手部接触、走路、放下和手机入口。


## 场景里的环形动作

点击宠物复用小屋现有圆形动作菜单（`actionOrbit`），首组为宠物面板、摸摸、抱起来/放下来、喂零食；更多行动为一起玩、叫过来、休息。动作直接调用与面板共用的入口，保留忙碌、暂停、缺少用户形象等校验；查看面板不受互动忙碌限制。菜单跟随宠物投影，设置最小显示尺寸，不随小模型缩成过小的按钮；手机横屏继续使用已有分页约束。打开面板会关闭圆圈菜单。原面板的状态、装扮、小记与照顾功能保留。

`art/pets/wheel-qa.mjs` 验证真实模型点击、面板动作、翻页直接互动、缺少形象时提示、手机按钮边界及 Escape。环形布局现在可返回四个位置，家具仍保持原来的三项分页。

宠物菜单使用与小人社交菜单相同的 socialWheelLayout 和 social-petal 圆钮：奶油底、暖棕线条、独立文字标签、粉色摸摸爱心。底部返回/页码/下一组导航，返回先退上一页、第一页返回关闭。短屏每页三项；家具菜单保持原样。
