# 厨房家具与吃饭

来源为用户提供的 `Meshy_AI_assets_20260916_073605.zip`。10 个源模型清理成 15 件家具：宠物双碗、猫耳垃圾桶、餐桌、餐椅、花瓶、餐巾篮、厨房推车、水槽柜、调料架、电器架、灶台、双门冰箱、中岛、水果碗和猫耳点心罐。餐桌和中岛的桌面摆件已独立，柜体内部的固定内容保留。

## 制作与重建

- `art/jellyfish-home/sources/kitchen-1-geometry.glb` 到 `kitchen-10-geometry.glb` 仅保留几何；不使用原图片、UV 或顶点色，也不采样 AI 贴图重涂。
- `pnpm node art/jellyfish-home/kitchen-assets.mjs` 按几何部件重新赋予奶油、薄荷、粉色等纯色材质，原木严格沿用阅读茶几 `woodLight`。同材质合批，平滑法线、保留必要硬边。
- 餐桌桌面重建为平滑平板，桌下碰撞盒仅覆盖桌腿和台面；餐椅按原比例保留猫耳靠背，校准朝向和坐位。桌面松散物品作为 `tabletop` 资产使用已有承托规则。
- 冰箱保留造型门板，实心柜体改为空腔、隔板和食物小件，两扇上门有独立铰链；下方两层抽屉保持关闭。门板内外面随铰链整体旋转。
- 每件无图 GLB 小于 200 KB / 6,000 三角形；普通物品按材质合批。冰箱为独立开合门板保留较多批次，实际导出报告见 `output/kitchen/assets-report.json`。没有增加 WebGL 渲染器。

## 分类与交互

- 「厨房」按 `collection: kitchen` 筛选；宠物双碗归独立「宠物」类，`category/collection: pets`，不混入可浇水的绿植类。
- 厨房架提供「摆好餐桌和两张餐椅」。需整组有空地才放入，失败不产生半套家具，遵守手机家具预算，撤销/重做视为一次修改。
- 餐桌 `dining: true`，四侧 `chairSlots`；默认前后各一张餐椅，复用 `dockId/dockSlot`，整套平移、旋转、收纳跟随已有桌椅规则。左右两侧也可放椅子，但互动另行检查角色空间。
- `diningActivities` 仅对实际对齐、未收纳且有坐位的吸附餐椅生成「坐到餐桌边吃饭」。检查头部空间、手可到达的桌边高度/距离、碗所在桌面是否被占用；不向所有未知桌椅盲目开放。
- 吃饭播放约 12 秒：手球与勺子共用 `eatingHand` 轨迹，从桌边移向嘴边；轻微点头、小脚晃动。结束后继续坐好；挥手等普通表情中止吃饭而保留坐位。站起、收纳或移动使活动失效时收起碗勺。
- 碗、米饭和勺子为一次创建、复用的纯几何道具，挂在角色下方，共用角色朝向和缩放。动作不修改角色保存外观、手脚大小或家具存档。
- 选中冰箱后可「打开冰箱 / 关上冰箱」；先检查门前扫掠空间、墙体、家具和当前角色。两扇上门各打开约 85°。同一时间开一台，移动/收纳/重建布置时关闭；开门状态不保存，尚不包含角色取食物行为。
- 门动画期间才请求重绘及阴影更新，减弱动态效果时直接到位。静止不持续刷新门板；退出编辑器统一释放临时几何和材质。

## 检查入口

`utils/room3dDining.test.ts` 检查餐桌椅关系、四方向动作位置、空位/障碍和冰箱开门空间。

`pnpm node art/jellyfish-home/kitchen-qa.mjs` 使用独立 `test/fixtures/room3d-kitchen.html` 验证真实 chibi 吃饭、四颗动作球显示/恢复、球体不伸长、碗与台面高度、冰箱动画/旋转/收纳和资源复用、手机整套摆放与撤销重做。`test/fixtures/kitchen-assets-gallery.html` 可检查全套造型和纯色。

这些家具沿用校准座椅规程；多人占位和自主走近吃饭仍需后续接入，当前使用小人面板手动开始。
