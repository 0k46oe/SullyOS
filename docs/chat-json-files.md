# 聊天与协同工作中的 JSON 文件

普通聊天的「＋ → JSON」可以发送 JSON 文件。发送后显示文件卡片，原文件保存在本机附件资产库；点击卡片可下载或分享。生成仍沿用聊天的手动／自动回复设置。

JSON 会先校验，再识别为酒馆 Chat Completion 预设、角色卡、世界书或通用 JSON。文件内容作为资料进入模型上下文，不自动安装预设，也不执行里面的宏、脚本或动作标签。

协同窗口的附件按钮同样接受 JSON，上传后显示识别类型。需要导出时选择「JSON」交付格式，或在消息里要求「修改后给我 JSON 文件」。普通聊天也支持同样的要求，生成成功后会收到可下载的 `.json` 卡片。

单个 JSON 最大 20MB。每个文件最多向模型提供前 300,000 个字符，超过时明确标注截断；下载和备份保留完整原件。模型实际可处理的上下文和输出长度仍由所用 API 决定。

JSON 文件相关的普通聊天回合使用本地生成。即时对话打开时会显示说明，需要保持页面打开直到完成；现有云端推送分段不能保证保留文件正文。协同工作沿用其独立 API。

实现与检查：

- `utils/jsonFile.ts`：格式校验、分类、上下文上限和 JSON 文件输出协议。
- `utils/chatPrompts.ts`：JSON 附件原文进入上下文，避开聊天双语标签清理。
- `utils/applyAssistantPostProcessing.ts`：先分离文件正文，再运行聊天动作解析；只交付合法 JSON。
- `features/collaboration/files.ts`：协同 JSON 读取与输出校验。
- `utils/jsonFile.test.ts`、`utils/chatJsonFiles.test.ts`：读取、请求内容、下载资产、备份、标签保真、非法格式和流式显示回归。
