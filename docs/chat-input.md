# 私聊与群聊输入设置

入口：私聊底部「＋」→「设置」→「输入与发送」，或群聊「群设置」→「输入与发送」。四项输入习惯在当前设备的所有私聊和群聊之间共用，修改后点击底部「保存设置」或「保存修改」。

- **发送按钮代替生成按钮**：输入框有光标时发送文字，点击聊天空白处后变为生成回复；未发送草稿保留。群聊沿用导演／轮询模式，生成期间保留顶部停止按钮。
- **回车发送文字**：开启后回车发送，Shift + 回车换行；关闭后回车只换行。输入法选字回车不会误发。
- **发完后自动生成回复**：发送成功、输入框无草稿和光标、面板及弹窗收起后等 2 秒触发。继续输入、发送或处理图片期间暂停；倒计时可取消。手动生成、退出聊天、切群或关闭开关会取消等待，不因加载历史补触发。群聊使用原有导演／轮询流程，无需新的 API 或后台配置。
- **表情包智能匹配**：见下节。

## 表情包智能匹配

- 默认关闭；旧存档缺少该字段时也保持关闭。
- 输入“抱”可匹配“抱抱”“给你抱抱”等名称，完全匹配优先，其次是名称开头、名称中包含输入文字。短句里出现完整表情名称也可匹配。
- 私聊从当前角色可见的所有分类中查找，群聊从群聊表情库全部分类中查找，不受表情面板当前分类限制。相同图片去重，最多显示八个候选，可左右滑动。
- 点击候选通过现有表情发送流程发送一次，保留未发送的文字草稿。当前候选行收起；继续修改输入后重新匹配。
- 输入法组词时不显示联想，选字回车不会误发。空输入、无匹配、消息多选或展开底部其他面板时不显示候选行。
- 只在本地匹配表情名称，不请求模型，也不新增输入内容埋点。

`utils/chatInputPreferences.ts` 的四个字段统一存到 `sully-chat-input-preferences-v1`，沿用现有完整备份的输入偏好字段。匹配逻辑在 `utils/emojiSuggestions.ts`，候选显示在 `ChatInputArea`；私聊传入已有的角色可见表情列表，群聊传入其完整表情库。群聊点击候选复用原有表情消息落库和引用流程并保留草稿；切群会重置上个群收起的联想状态。只有开启自动回复且满足等待条件才触发模型。

### 与社区美化兼容

表情联想和自动回复倒计时位于 `.sully-chat-inputbar` 外侧的同级区域，不插入输入栏内部。显示、收起辅助提示不会改变原有 `> div:first-child` / `:nth-child(1)` 的输入行目标，也不会重建输入框、丢失草稿或光标。

新美化建议使用固定钩子：`.sully-chat-composer`（输入行）、`.sully-chat-input-wrap`（输入框外壳）、`.sully-chat-textarea`、`.sully-chat-actions-button`、`.sully-chat-send-button`。联想区可单独用 `.sully-chat-emoji-suggestions` 定制（旧 `.sully-emoji-suggestions` 仍保留），倒计时用 `.sully-chat-auto-reply`。不改写用户保存的 CSS。

## 折叠设置

聊天设置分为六组，默认全部收起：输入与发送、聊天外观、上下文与记忆、翻译与语音、扩展功能、聊天记录。标题行常显，点击或键盘操作可展开；折叠不会丢失未保存的修改。各项原有的保存方式和执行行为不变。

## 工具区自定义排列

私聊底部「＋」右上角的「整理工具」打开完整工具网格。拖动每项右上角的手柄排序，靠近网格上下边缘时自动滚动；普通空白处仍可滑动浏览。键盘聚焦手柄后可用左右方向键移动一格、上下方向键移动一行。每八项对应工具区的一页。

「完成」后保存；返回、关闭、Escape 放弃本次修改。「恢复默认」也需要点完成才生效。所有私聊共用当前设备的排列，不改群聊自带工具，也不增加或删减任何功能。新功能自动追加到末尾；移除的功能和重复 ID 在读取时剔除。配置单独保存在 localStorage `sully-chat-action-order-v1`，当前不包含在跨设备系统备份中；存储失败会提示仅本次打开生效。

新增的「查找聊天记录」也可拖到第一页，具体范围与退出方式见 [聊天记录](chat-records.md#独立查找与日期浏览)。
