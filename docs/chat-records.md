# 角色身份、完整聊天导出与本地高频词

入口为每个私聊窗口的「聊天设置」。

## 角色身份

「角色身份 → 默认 AI 伴侣提示词」按角色保存，切换立即生效。原有普通角色保持默认行为：核心指令为空时补入“你是一个温柔、拟人化的AI伴侣。”。关闭时改为按人物设定扮演，不补入默认 AI 伴侣身份；已保存的完全相同默认句也被视为默认身份处理。其他自定义核心指令、人物描述和世界观保留，用户写入自定义指令的身份内容需自行修改。

酒馆角色卡导入后默认关闭。此前已导入且仍有 `tavernImport` 信息的角色也自动使用关闭默认；用户手动设置优先。该选择由共享 ContextBuilder 使用，角色核心上下文、轻量角色上下文和角色统计口径一致，云端提示词沿既有角色更新同步路径刷新。

## 聊天记录

「聊天记录」提供 JSON 与 TXT 导出，可选包含已保存的思考内容。默认不包含，清除 `metadata.thinkingChain`、历史 reasoning 字段与助手正文中的 `<think>` / `<thinking>` / `<thought>` 块；附件脚本里的同名文本属于文件数据，不当作思考删除。

每次导出重新读取 IndexedDB 中该角色的完整私聊历史，包含已归档但未删除的原文，筛出用户和 AI 消息，按原时间戳及 ID 排序。不会按当前屏幕页数、上下文上限或宫殿水位裁剪，不含群聊和系统日志。JSON 保留消息正文、类型、时间戳、引用与元数据；TXT 提供可读正文及卡片原始数据。日期显示跟随用户设备时区。图片、音频与附件保留原始引用或说明，不打包二进制资源，也不提供重导入功能。

思考选项仅针对当时已落库的内容，不调用 API 补写。导出复用现有密钥扫描确认和原生分享 / 浏览器下载流程，不把角色完整配置、API 设置写进文件。

## 高频词

点击「统计高频词」后，在本地读取相同范围的历史，分用户和 AI 统计前 30 个词及出现次数。每次刷新重新读取；支持过滤常见中英文虚词和包含单字词。

只统计 text 正文和 voice 转写，排除思考、双语翻译副本、代码围栏、工具指令、资源地址。附件 JSON、脚本与卡片不计入。默认通过本地 Web Worker 和浏览器 `Intl.Segmenter` 词语分割；不支持分词的浏览器使用中文相邻双字，并在界面标明。无 Worker 的环境可直接在本地计算。此功能不调用模型、网络接口或计数 API，不消耗 Token；浏览器分词版本不同，词边界可能略有区别。

针对性检查：`utils/characterInstructions.test.ts`、`utils/chatRecords.test.ts`、`utils/chatRecordsPanel.test.tsx`，以及既有酒馆导入、角色统计和共享上下文回归测试。
