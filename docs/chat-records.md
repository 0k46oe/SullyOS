# 角色身份、完整聊天导出与本地高频词

角色身份与高频词入口在每个私聊窗口的「聊天设置」；聊天导出位于加号菜单。

## 角色身份

「角色身份 → 默认 AI 伴侣提示词」按角色保存，切换立即生效。原有普通角色保持默认行为：核心指令为空时补入“你是一个温柔、拟人化的AI伴侣。”。关闭时改为按人物设定扮演，不补入默认 AI 伴侣身份；已保存的完全相同默认句也被视为默认身份处理。其他自定义核心指令、人物描述和世界观保留，用户写入自定义指令的身份内容需自行修改。

酒馆角色卡导入后默认关闭。此前已导入且仍有 `tavernImport` 信息的角色也自动使用关闭默认；用户手动设置优先。该选择由共享 ContextBuilder 使用，角色核心上下文、轻量角色上下文和角色统计口径一致，云端提示词沿既有角色更新同步路径刷新。

## 聊天记录

使用原作者聊天加号菜单的“导出聊天记录”入口，保留 TXT 原文格式（每条消息的原始时间和 User / AI 标识、媒体占位）。删除原二改在聊天设置里的 JSON / TXT 双导出实现。

新增“同时包含思考内容”复选框，默认不勾选。两种模式均导出完整聊天正文；勾选后追加对应回复的 `metadata.thinkingChain`，并保留助手原文中已有的思考块。不勾选时删除助手文字／语音正文里的完整及未闭合思考块。用户字面量和附件数据不按助手思考处理，不调用 API 补写。

每次重新读取该角色全部已保存消息，包含归档原文；沿用原作者的消息可见性、排序、文件名和分享／下载流程。图片、音频及附件保留占位或原文引用，不打包资源。

## 独立查找与日期浏览

私聊底部「＋」→「查找聊天记录」提供独立页面；可在「整理工具」中把它移到常用位置。读取当前角色完整已保存的私聊记录，包括已经归档但仍保留的原文，不受 AI 的上下文上限、用户断点和记忆水位限制。见面、通话、家园、剧情副本、群聊、系统提示及秘密小纸条不混入普通聊天查找；删除后只剩摘要的原文无法搜索。

支持内容关键词、发送者（全部 / 我 / 当前角色）和日期组合筛选；大小写与全角半角归一化，结果显示发送者、原始收发时间和命中正文片段，每页 40 条，全部结果均可翻页。默认最近的在前，选择某天后按当天收发顺序排列。图片与表情显示占位，语音查转写，JSON 文件查文件名；不展开原始卡片载荷、附件脚本或角色思考。正文以普通文本呈现，不执行 HTML 或脚本。

「按日期」打开月历，圆点表示当天有聊天，空白日期禁用；可切换年月直接定位往年。日期以用户设备的日历日为准，与聊天收发时间显示一致，不使用角色设定时区或 UTC 日期代替。日期标记统计该角色当天全部可见聊天，不随关键词或发送者筛选消失。

点击结果关闭查找并定位原消息，约 2.2 秒后清除高亮；切角色、退出历史或再次跳转会清理上次的计时器。目标周围先挂载少量消息，上下滑到边缘再分批加载；不会因收到新回复强制拉走正在看的位置。向下翻到最新消息会无提示恢复正常聊天；聚焦输入框、发送消息或触发回复会回到最新位置。局部返回键先退出查找页／输入状态，再退出历史浏览，不显示醒目的「回到当前聊天」浮层。

设置里的入口更名为「设置 AI 原文读取范围 / 用户断点」，移除长按跳转。该页继续只管理 AI 读取边界，普通查找和定位不修改角色设定、用户断点或记忆水位。搜索与日期统计全部在本地完成，不调用模型；长历史分批建索引，可在关闭或切角色时取消。

实现：`ChatRecordSearch`、`chatRecordSearch.ts`、`ChatActionOrderEditor`、`chatActionOrder.ts`。针对性检查：`utils/chatRecordSearch.test.ts`、`utils/chatActionOrder.test.ts`、`utils/chatTools.ui.test.ts`，以及既有聊天输入、历史窗口、消息可见性与上下文范围测试。

## 酒馆角色专属用户档案

神经链接的酒馆角色中提供“专属用户档案”：默认关闭，开启后设置自己的姓名与个人设定，只替换这个角色读取的用户身份。姓名为空沿用全局姓名，简介为空则不发送全局简介。关闭恢复全局“档案”，不会改动全局数据。

共享 ContextBuilder、世界书 `{{user}}` 宏、聊天历史／思考提示、见面与协同、主动消息模板使用同一解析；角色统计预览也沿用该口径。剧情默认用户面具使用开场白角色（没有开场白时为首位角色）的档案，显式选择的角色面具／自定义面具优先。多角色剧情中使用一个共同用户身份。

字段随完整系统备份保存；分享角色卡时双向剥离，避免把私有玩家档案带给别人。

## 高频词

点击「统计高频词」后，在本地读取相同范围的历史，分用户和 AI 统计前 30 个词及出现次数。每次刷新重新读取；支持过滤常见中英文虚词和包含单字词。“这是”“那是”“那么”“就是说”等语气／指示／衔接词默认过滤，不影响有意义的内容词。

只统计 text 正文和 voice 转写，排除思考、双语翻译副本、代码围栏、工具指令、资源地址。附件 JSON、脚本与卡片不计入。默认通过本地 Web Worker 和浏览器 `Intl.Segmenter` 词语分割；不支持分词的浏览器使用中文相邻双字，并在界面标明。无 Worker 的环境可直接在本地计算。此功能不调用模型、网络接口或计数 API，不消耗 Token；浏览器分词版本不同，词边界可能略有区别。

针对性检查：`utils/characterInstructions.test.ts`、`utils/chatTextExport.test.ts`、`utils/characterUserProfile.test.ts`、`utils/chatWordInputs.test.ts`、`utils/chatWordFrequencyPanel.test.tsx`，以及既有酒馆导入、角色统计和共享上下文回归测试。
